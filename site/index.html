Conecta tu GitHub

Para leer precios en vivo, seguir artículos y guardar ajustes desde la web hace falta una clave de tu cuenta de GitHub. Se hace una vez por navegador.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: Radar Airsoft. Caducidad: la que quieras (por ejemplo, 1 año).
  3. Repository access → Only select repositories → radar-airsoft.
  4. Permissions → Repository permissions: Actions = Read and write · Contents = Read-only.
  5. Generate token, cópiala y pégala aquí:

La clave se queda solo en este navegador. Sin ella también puedes seguir artículos enviando a tu bot de Telegram /seguir enlace 150 20%.
