Configurar precios en vivo (una sola vez en este navegador)
  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: Radar en vivo. Caducidad: la que quieras (por ejemplo, 1 año).
  3. En Repository access elige Only select repositories → radar-airsoft.
  4. En Permissions → Repository permissions: Actions = Read and write, y Contents = Read-only.
